CÓMO VER EL PROYECTO EN TU COMPUTADORA 💻

Si quieres descargar el código y verlo en tu compu, te cuento cómo:

📍 Paso 1: Abre tu terminal o CMD

- En Windows: Presiona Win + R, escribe "cmd" y dale Enter
- En Mac: Busca "Terminal" en Spotlight  
- En Linux: Ctrl + Alt + T


📂 Paso 2: Ve a la carpeta donde quieres guardar el proyecto

Por ejemplo, si quieres guardarlo en Documentos:

cd Documents

o en el escritorio:

cd Desktop


⬇️ Paso 3: Descarga el proyecto con este comando

git clone https://github.com/dayalopez231007-ship-it/galeria-visual--kerly_dayanna_lopez-_transferencia-.git
Esto va a crear una carpeta con todo el proyecto dentro.


📁 Paso 4: Entra a la carpeta que se acaba de crear

cd galeria-visual-keryly


🌐 Paso 5: Abre el archivo index.html

Opción A: Haz doble clic en el archivo index.html desde tu explorador de archivos

Opción B: Si usas Visual Studio Code, abre la carpeta completa y usa Live Server (click derecho en index.html → Open with Live Server)

Opción C: Arrastra el archivo index.html a tu navegador (Chrome, Firefox, etc.)

Y listo! Ya deberías verlo funcionando en tu navegador 🎉


POR QUÉ HICE LAS COSAS COMO LAS HICE 💭

🎨 Los colores que elegí

Cuando pensé en Dragon Ball me acordé de tres cosas principales: el uniforme naranja de Goku, el pelo dorado cuando se transforma en Super Saiyan, y el azul del Kamehameha. Entonces usé esos colores en todo el diseño porque me parecieron los más representativos.

🧡 Naranja para lo más importante y cuando pasas el mouse sobre las cosas
💛 Dorado para los brillos y efectos especiales (mi favorito!)
💙 Azul para el banner de arriba
🖤 Gris oscuro para los textos, para que se lean bien

No fue nada científico, solo me pareció que quedaba lindo y representaba bien la serie.


✨ Los gradientes (esos fondos que cambian de color)

El header que brilla ⚡

Quería que el encabezado tuviera ese efecto de aura dorada, como cuando Goku se transforma. Por eso se mueve constantemente, como si estuviera vibrando con energía. Probé con diferentes velocidades pero 8 segundos me pareció lo mejor, más rápido se veía muy agresivo y mareaba un poquito.

El banner azul 🌊

Para la sección promocional usé tonos azules como el Kamehameha. Le puse un ángulo diagonal porque se veía más dinámico que uno recto. Cuando pasas el mouse encima se eleva un poquito y brilla, como diciendo "hey, mírame" ✨


📸 Las imágenes


Todas las imágenes están en formato .webp porque pesan menos que los PNG o JPG normales. Básicamente la página carga más rápido y se ven igual de bien.🎯

Cómo las acomodé

Usé "background-size: contain" para que se vean los personajes completos. Al principio probé con "cover" pero a algunos se les cortaba la cabeza o los pies y se veía súper raro 😅 Así todos salen completos en sus cuadros.


🌙 Las transparencias (capas oscuras que ves)

En el header le puse una capa negra semi-transparente porque sin eso no se leía bien el texto blanco. Simple pero necesario para que se vea prolijo.

En las tarjetas cuando pasas el mouse aparece un gradiente oscuro de arriba hacia abajo. No es nada del otro mundo pero hace que se sienta más interactivo y da ese toque especial 💫 También la imagen hace zoom, me encanta ese efecto.


✨ Las sombras en el texto

El título tiene varias capas de sombra para que tenga ese efecto de brillo dorado y al mismo tiempo se lea bien sobre cualquier fondo. Son como tres o cuatro sombras apiladas, suena complicado pero es copiar y pegar nomás. Le da ese toque mágico que buscaba 🌟


🛠️ CON QUÉ ESTÁ HECHO

Solo HTML y CSS, nada más. No usé Bootstrap ni librerías fancy, todo escrito a mano para practicar bien. Lo subí a GitHub Pages para que se pueda ver online gratis 🌐
